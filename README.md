## What this entry is

One single-line excuse someone could send to call in sick: under 200
characters, half-believable, specific and visual, with the punch landing at
the very end. The line is the only thing in `main.ts`; the program validates
it and writes it to `entry.txt`.

> Won't be in — the smoke alarm's been chirping every 40 seconds all night and I'm on a chair with a screwdriver, so at this point one of us is getting replaced.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt`. Pass `--help` for usage.
